Cheatsheets

The commands and keys you use most, each with what it does in plain words. Commands act on the site of the current folder, or on the one named with --site "My Site".

Start here

  • sync-servers site add sets up a site and its server, asking each question in turn.
  • sync-servers sync --put, in the site's folder, previews your changes and sends what you check.
  • ? on any screen of the interface lists every key of that screen.

Preview keys

The menu at the bottom of the preview, then the keys ? adds:

Keys of the preview
KeyDoes
Space = Check/UncheckChecks or unchecks the focused file
p = PutSends the file to the server
g = GetBrings the file down from the server
s = SkipLeaves the file as it is
d = DiffShows how the two copies differ
a = AllChecks or unchecks every file that can run
q = QuitQuits, transferring nothing, as Ctrl+C does
Enter = SynchronizeRuns the checked files, after one question
mRecords both copies as in sync without moving the file
xDeletes the file, asking where when both copies exist
TabShows only one kind of row: All, Put, Get, Resolve, Delete, Guarded or Errors
/Finds a path as you type
EscGoes back, transferring nothing
