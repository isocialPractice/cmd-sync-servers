Options

Everything that changes how sync-servers runs, in one place: options on the command line, environment variables, and the ways a preview can be shown. The settings kept in sites.json are on Configuration.

Environment variables

Variables sync-servers reads
VariableDoes
SYNC_SERVERS_HOMEMoves the settings folder there, and the state folder to its state folder.
SYNC_SERVERS_SITEThe site to use when a command names none, by name or id.
SYNC_SERVERS_PASSWORDThe password of the server in use, for unattended runs. A saved password comes first.
SYNC_SERVERS_KEY_PASSPHRASEThe passphrase of the private key of the server in use.
SYNC_SERVERS_KEYRINGoff, 0, false or no turns the operating system's credential store off.
SYNC_SERVERS_UIHow previews are shown when --preview is not given: tui, editor, plain or none.
SYNC_SERVERS_EDITORThe editor for editor mode, --editor and config edit, with its arguments, such as code --wait.
VISUAL, EDITORThe editor when SYNC_SERVERS_EDITOR is not set, in that order. Without any, Notepad on Windows, then nano or vi.
SSH_AUTH_SOCKThe SSH agent for the agent sign-in method. On Windows the OpenSSH agent is used when it is not set.
NO_COLORAny value but an empty one turns colour off, as --no-color does. Nothing depends on colour.
TERM=dumbASCII symbols and plain prompts, with no full-screen drawing.

Setting one for a single command:

SYNC_SERVERS_UI=plain sync-servers sync --put

In cmd.exe, for the rest of the session:

set "SYNC_SERVERS_UI=plain"
sync-servers sync --put

Preview modes

sync, and put or get when a decision is needed, show a preview before anything moves. --preview chooses how:

Values of --preview
ModeShows the preview
tuiFull screen, row by row. The default in a terminal.
editorAs a text file in your editor; see Editor mode.
plainAs numbered rows and typed commands; see Plain mode.
nonePrinted, then one yes or no question in a terminal. The default without a terminal.

Without --preview, the mode is none when nobody can answer: with --yes, --dry-run, --json, or no terminal. Otherwise it comes from SYNC_SERVERS_UI, else tui, which becomes plain with --plain, with TERM=dumb, or in a terminal that cannot take single key presses.
